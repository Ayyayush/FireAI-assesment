# Reflection

## What I Observed
I chose Print Mega Mess because it was a place I could visit easily and see how things actually work. After visiting the shop, I noticed that managing printing orders is not just about printing pages. There are many small things like keeping track of documents, counting pages and calculating the charges, which can take time when done manually.


## Conversation and Learning
Talking to Aditya gave me a better idea of how he handles his daily work. I came to know that managing multiple print jobs and calculating the cost for each customer can sometimes get confusing, especially when there are many orders. I hadn't really thought about these problems before visiting the shop, so it was interesting to see how such a simple task could be made easier with a small tool.


## Building PrintDesk
Building PrintDesk took more time than I expected. I faced some issues while connecting the frontend with the backend and handling the data through CSV files. Some things worked initially, but later I found issues while testing and had to fix them. It was a good experience because I got to work on something beyond just writing code and actually try to make the features work together.


## Limitations
The application still needs some improvement. Most of the document and stock details have to be entered manually, so there is a chance of mistakes if the data is incorrect. I also haven't used it for the shop's actual daily work yet, so I can't say how well it will handle everything in a real situation.


## Looking Back
This assignment was useful because I got to observe a real problem instead of just choosing an idea and building something around it. I also realised that even a small application can take quite a bit of effort to build properly. If I had more time, I would make a few improvements to PrintDesk and let Aditya try it during his daily work to see what needs to be changed or added.
